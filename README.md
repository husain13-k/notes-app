# Notes App

Simple Notes App using Java Spring Boot.

## Features

- Create Notes
- Search Notes
- CRUD APIs
- In-memory storage
- Case-insensitive search

## Tech Stack

- Java 17
- Spring Boot
- HTML
- CSS
- JavaScript

## Run Project

Open in IntelliJ or vscode and run:

NotesAppApplication.java

Then open:

http://localhost:8080
